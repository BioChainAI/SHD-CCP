## JSON envelope

Every `*.json` file validates against [`schema.json`](schema.json):

```json
{
  "suite": "garner_crt_881_883_887",
  "spec_version": "0.1.0",
  "rfc": "02",
  "status": "normative | draft | pending",
  "description": "...",
  "generator": "...",
  "binary": { "file": "garner_crt_881_883_887.bin", "fields": ["n", "r881", "r883", "r887"] },
  "cases": [ ... ]
}
```

Values that can exceed 2^53 are written as strings so JavaScript and other double-based JSON parsers stay exact. Tiles and payloads are `"0x"`-prefixed 16-digit hex. Gram-TQF values are decimal.

## Binary mirror (`SHDGEV01`)

Use these files in languages without a JSON parser in the standard library (C, Rust `no_std`, Elixir bitstrings). All integers are little-endian:

| Offset | Size | Field |
| ---: | :--- | :--- |
| 0 | 8 bytes | magic `SHDGEV01` |
| 8 | u32 | fields per record *F* |
| 12 | u32 | record count *N* |
| 16 | *N* × *F* × u64 | records, field order given by `binary.fields`. Signed values are two's complement. |
